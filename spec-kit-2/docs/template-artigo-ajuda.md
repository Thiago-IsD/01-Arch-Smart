## Regras de escrita

Apagar esta seção ao usar o template.

- **Linguagem do arquiteto**, não do dev. "Preencher", nunca "normalizar". "Arquivo", nunca "builder". "Receita", nunca "entrada". Glossário completo em `product/01-visao-de-produto.md` §9.
- **Curto.** Se passa de uma tela de rolagem, provavelmente são dois artigos.
- **Captura de tela** onde a palavra sozinha não resolve — e atualizada quando a tela mudar.
- **Sem jargão de produto.** Nada de "entitlements", "tenant", "onboarding".
- **Voz ativa e segunda pessoa.** "Clique em Novo projeto", não "deve-se clicar".
- **Nunca prometa o que o produto não faz.** Doc de usuário é contrato.
